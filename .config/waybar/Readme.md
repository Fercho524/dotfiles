# Super Waybar

Run waybar

```sh
~/.config/waybar/waybar.sh &
```

## Creating a new theme

```sh
./build/add_theme.sh yourtheme
```

Automatically it will create 3 files, `layout.jsonc` , `style.css` and `run.sh`  into respective folders, this is not diferent of use html,css and javascript. It will provide a template to start a new theme. Now you have to include it in  `waybar.sh`

```sh
#!/bin/sh

killall waybar
source ~/.config/waybar/themes/yourtheme/run.sh
```

And run the script:
```
~/.config/waybar/waybar.sh &
```

## Delete theme

It will delete all files of your theme

```
bash ./build/del_theme yourtheme
```

## Customizing your theme

Go to `./themes/yourtheme/run.sh`

```sh
#!/bin/bash

# Executables
MODULE_LINKER=~/.config/waybar/build/generate_include.py
LAYOUT_GENERATOR=~/.config/waybar/build/generate_layout.py

# Config
MODULES_FOLDER=~/.config/waybar/modules
MODULES_FILE=~/.config/waybar/include/modules.jsonc
LAYOUT_FILE=~/.config/waybar/layouts/tonal/layout.jsonc
LAYOUT_STYLE=~/.config/waybar/styles/tonal/style.css

# Linking Modules
python $MODULE_LINKER --dirs $MODULES_FOLDER --output $MODULES_FILE                                                                       
# Layouts
python $LAYOUT_GENERATOR \
--input $LAYOUT_FILE \
--modules-file $MODULES_FILE \
--output $LAYOUT_FILE \
--left custom/launcher hyprland/workspaces disk custom/network \
--center wlr/taskbar \
--right pulseaudio custom/cpu memory tray clock \
--position bottom \
--margin "8 8 0 8" \
--height 44

# Exec waybar
waybar -c $LAYOUT_FILE -s $LAYOUT_STYLE
```

**MODULE_LINKER** and **LAYOUT_GENERATOR** are the scripts to link the modules and create the layout, don't edit it.

**MODULES_FOLDER**
This is the place of your modules in .jsonc format

**MODULES_FILE**
This is an autogenerated file that links all your modules in the folder, it should be included in your layout.

```sh
python ~/.config/waybar/build/generate_include.py \
	--dirs ~/.config/waybar/modules \
	--output ~/.config/waybar/include/modules.jsonc
```

**LAYOUT_FILE**
Its your base config, its an opcional file if you are creating a new theme. This is the path where your layout will be saved. For more information about layout building, you can use:

```
python ~/.config/waybar/build/generate_layout.py --help
```

You can generate multiple layouts for multiple panels, and then, execute it changing the configs and styles in waybar arguments.

**LAYOUT_STYLE**
For each layout that you create, you need to style it with css, this is the location of the style.

### Integration with Pywal
You need to edit `./styles/yourtheme/style.css` and include

```css
@import "../../../../.cache/wal/colors-waybar.css";

#workspaces button {
  color: @foreground;
}
```

## Recomendations
1. Always use a subfolder for your theme in the styles, layouts and themes folders, this is a way to scale your settings.
2. Dont kill wabar in your run.sh, and dont start waybar in the waybar.sh, if you do this you will only have a single panel.
3. Dont mix styles, layouts between themes, it should preserve a clean arquitecture and dont mix functions.
